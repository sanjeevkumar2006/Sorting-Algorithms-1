# Summary

This project demonstrates two different methods to calculate the factorial of a number in Python:

1. Iterative Method
2. Recursive Method

The program takes a number as input from the user and calculates its factorial using the selected method. It also measures the execution time of the method and displays its time and space complexity.

# Iterative Method

The iterative method uses a `for` loop to calculate the factorial.

# Time Complexity
`O(n)`

# Space Complexity
`O(1)`

The iterative method does not use additional memory that grows with the input size.

# Recursive Method

The recursive method calculates the factorial by calling the same function repeatedly until it reaches the base case.

# Time Complexity
`O(n)`

# Space Complexity
`O(n)`
