Summary

binary.py – Implements binary search on a sorted array. Takes user input for the array size, sorted elements, and target value. Measures execution time and displays time complexity (O(1) best case, O(log n) average/worst case).

linear.py – Implements linear search that iterates through an array element by element. Takes array size, individual elements, and target value as user input. Displays execution time and time complexity (O(1) best case, O(n) average/worst case).

Key Difference: Binary search is faster (logarithmic) but requires a sorted array, while linear search works on any array but is slower (linear).

Both programs include timing measurements and complexity analysis displays.
